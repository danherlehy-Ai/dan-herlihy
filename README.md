# dan-herlehy

The personal website of **Dan Herlehy** — entrepreneur, e-commerce operator, automation builder, and Thousand Islands boater. Public repo.

## View it

Open `index.html` in a browser, or serve the folder locally:

```sh
cd dan-herlehy && python3 -m http.server 8080
```

(If GitHub Pages is enabled on this repo, it's also published there.)

## Structure

```
index.html              — the whole site (single page)
assets/css/style.css    — dark editorial theme, gold accents
assets/js/main.js       — reveal-on-scroll + header effects
assets/img/             — self-hosted images
```

## Images

All images are self-hosted in `assets/img/` — no hotlinking:

| File | What | Source |
|---|---|---|
| `studio-house.webp` | Photo Scanning Studio building | photoscanningstudio.com (Dan's own site) |
| `studio-collage.jpg` | Snapshot collage from the studio | photoscanningstudio.com (Dan's own site) |
| `thousand-islands.jpg` | Boldt Castle from the water | Public image search (artofit.org gallery) |
| `boldt-aerial.webp` | Vintage aerial postcard, Heart Island | Public image search (picclick listing) |

**A note on portraits:** no publicly verifiable photo of Dan was found online, and using a stranger's photo (or an AI-generated face) on his personal site would be worse than none. The design uses a "DH" monogram instead. To add a real portrait, drop it in as `assets/img/portrait.jpg` and point the hero at it.

## Facts & honesty

Content is built from (a) publicly verifiable facts — e.g. PhotoScanningStudio.com's 5.0★ rating, published pricing, PuzzleSecret's book specs — and (b) Dan's own notes about his businesses. Anything Dan wants corrected, he can just say the word.
